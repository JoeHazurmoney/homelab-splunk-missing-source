# Analyst training deck (example)

This is a short example module for the analyst deck. Roadmap feature F7 builds the full deck. It has
seven slides and takes about 10 minutes. It teaches the first five minutes with a finding, then sets
one exercise. The exercise uses the Cribl DOWN rows.

- **The deck** is a Slides artifact on claude.ai:
  <https://claude.ai/artifact/XJE1Aa7VSD2P6ZoyyMU8ZY>. It is private until its owner shares it. It
  downloads as PowerPoint (.pptx) or PDF.
- **This folder** keeps its source: `project/deck.json`, `project/deck.css` and one HTML file per
  slide in `project/slides/`. The speaker notes are in each slide's `<aside>`.
- **The written guide** that goes with it is
  [example-analyst-first-five-minutes.md](../example-analyst-first-five-minutes.md).
- **The pictures** come from [the screenshots folder](../../screenshots/README.md).
- **The look** matches [the pitch deck](../../deck/README.md).
