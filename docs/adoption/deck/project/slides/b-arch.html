HL Data Health

Expected list: the inventory that deploys the inputs also writes the list of what should arrive.

Markers: automation posts a marker before planned work, straight to Splunk, not through Cribl.

Search-time SPL and the KV store only: no scripts, no custom commands, no index-time configuration.

Everything collected flows through Cribl, so the app treats Cribl as a relay: if Cribl stops, every row behind it says so, instead of each host alerting on its own. Agent identity and version come from the agent’s own internal logs, because behind a relay Splunk only sees Cribl’s connection. Markers go straight to Splunk’s HTTP Event Collector, so a Cribl outage cannot hide them.
