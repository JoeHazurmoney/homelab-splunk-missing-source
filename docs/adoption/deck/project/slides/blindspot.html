THE PROBLEM

Detections alert on what arrives. Few things watch for what stops.

A stopped agent, a broken input, a dropped route or a cleared log looks exactly like a quiet night. Every detection rule built on that data goes blind with it, and nobody is told.

Silence is the most expensive kind of finding: the one nobody sees.
The point to land: detections are only as good as the data under them. When a source goes silent there is no error, no alert, just an absence. Attackers know this: stopping the agent or clearing a log is a standard first move. Ask the room how long it would take them today to notice a single sourcetype stop on one host.
